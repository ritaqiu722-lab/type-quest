# Type Quest 英文打字冒險

數位科技概論期末作品：用闖關遊戲練習英文打字。

## 特色
- 4 個章節（鍵盤新手村 → 單字森林 → 句子城堡 → 速度競技場），逐步增加難度
- 打錯顯示紅色、正確顯示綠色，並在鍵盤上標示正確按鍵位置
- 練習完成後顯示 WPM 速度、正確率，並與第一次成績比較進步幅度
- 星星、徽章、連續簽到、個人紀錄（存在瀏覽器 localStorage）

## 如何執行
直接用瀏覽器開啟 `index.html` 即可，或使用 GitHub Pages 線上遊玩。

## 檔案
- `index.html` 頁面結構
- `style.css` 樣式
- `game.js` 遊戲邏輯
